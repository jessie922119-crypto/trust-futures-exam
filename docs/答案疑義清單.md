# 答案疑義清單

以下題目之官方答案，經本站對照官方法規後認為可能與當期（或應試時）規定不符。**官方答案未修改**，僅供讀者參考，歡迎指正。

| 題號 | 官方答案 | 疑義理由 | 來源 |
|---|---|---|---|
| TL-OF-45-31 | (3) | 信託業法第58條第2項（民國94年5月18日修正）規定罰鍰逾期三十日仍不繳納者「移送強制執行」，並未規定移送法院；依行政執行法第4條第1項，公法上金錢給付義務逾期不履行者，移送法務部行政執行署所屬行政執行處執行。第45期（民國107年）施行之條文下，選項(2)「法務部」（所屬行政執行署）較符法條，官方答案(3)「法院」疑係依修法前舊條文。 | https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=G0310027 ；https://law.moj.gov.tw/LawClass/LawHistory.aspx?pcode=G0310027 ；https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=A0030023 |
| TP-OF-41-75 | (3) | 信託資金集合管理運用管理辦法第6條第1項（103年10月31日以後之版本，第41期施行中）規定：集合管理運用帳戶之終止，除法令另有規定或存續期間屆滿外，應依約定條款之約定「經受益人會議決議通過」，並報主管機關核准或備查。官方答案認「受益人大會決議終止」非屬終止方式，與條文不符；本題四個選項似均屬法定終止程序之一環，題目或答案有疑義。 | https://law.moj.gov.tw/LawClass/LawOldVer.aspx?pcode=G0310034&lnndate=20150807&lser=001 |
| TP-OF-44-10 | (2) | 題目以「港澳地區陸資直接或間接持股達百分之三十以上之公司」為禁止投資標的。該百分之三十限制見於金管會96年9月7日金管證二字第0960044030號令及98年8月21日金管證券字第0980043062號令（均已廢止）；自101年10月17日金管證券字第10100424861號令起，證券商受託買賣外國有價證券（信託業依信託業營運範圍受益權轉讓限制風險揭露及行銷訂約管理辦法第12條第2款準用）僅禁止非專業投資人涉及「大陸地區證券市場」之有價證券。第44期（民國106年）時，四個選項均為港澳市場掛牌之公司，依當期規定似均無禁止，官方答案(2)有疑義。 | https://law.fsc.gov.tw/LawContent.aspx?id=FE065629 ；https://law.fsc.gov.tw/LawContent.aspx?id=GL000061 ；https://www.trust.org.tw/tw/law/view/6277 ；https://law.moj.gov.tw/LawClass/LawOldVer.aspx?pcode=G0380204&lnndate=20160509&lser=001 |
| TP-OF-47-10 | (3) | 理由同第44期第10題：選項(2)「香港地區證券市場由大陸地區政府、公司直接或間接持股達百分之四十之公司所發行之有價證券」依早期令（百分之三十限制）不得投資，但當期（民國108年）適用之令僅禁止非專業投資人涉及大陸地區證券市場之有價證券，(2)似亦得投資，本題可能有(2)(3)兩個正確選項。 | https://www.trust.org.tw/tw/law/view/6277 ；https://www.selaw.com.tw/Chinese/AdministrativeOrderResult?guid=2e24eb2b-5669-462d-b4ae-4ec8254e8ddd |
| TP-OF-48-45 | (2) | 「受益證券持有人每年度至少335日合計應達50人以上」之規定，見於民國93年6月3日版「受託機構募集或私募不動產投資信託或資產信託受益證券處理辦法」第6條，99年4月1日修正後已刪除。第48期（民國108年）應試時已無此規定，題目所據規定已失效。 | https://law.moj.gov.tw/LawClass/LawOldVer.aspx?pcode=G0380172&lnndate=20040603&lser=001 ；https://law.moj.gov.tw/LawClass/LawOldVer.aspx?pcode=G0380172&lnndate=20100401&lser=001 |
| TL-OF-48-48 | (4) | 題目所引「信託業內部控制及稽核制度實施辦法」已於民國99年3月29日廢止，現行「金融控股公司及銀行業內部控制及稽核制度實施辦法」未見「營業單位襄理級以上人員以具稽核經驗者優先」之規定；第48期（民國108年）應試時題目所據規定已失效。 | https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=G0310031 ；https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=G0380218 |
| TP-OF-45-66 | (3) | 各類所得扣繳率標準第3條於民國106年12月29日修正，非居住者取得股利之扣繳率由百分之二十提高為百分之二十一。第45期（民國107年）如係於修正後應試，股利部分官方答案百分之二十與當期規定不符（利息部分仍為百分之二十，公債、公司債等為百分之十五），屬待確認之疑義。 | https://law.moj.gov.tw/LawClass/LawOldVer.aspx?pcode=G0340028&lnndate=20171229&lser=001 ；https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=G0340028 |
| TP-OF-44-09 | (1) | 金管會104年9月1日金管銀外字第10400192770號令第2點規定，OBU辦理外幣信託業務於「管理、運用與處分信託資產之種類及範圍」不受信託業法等限制，顯示OBU得運用外幣信託財產，選項D似亦正確，答案或應為(4)僅AD。 | https://www.trust.org.tw/upload/1110630000001.pdf（第225頁） |
